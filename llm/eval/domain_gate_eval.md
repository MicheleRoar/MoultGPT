# Domain gate — real evaluation

Generated by running the production domain gate (`domain/domain_gate.py`, via `pipeline/domain_pipeline.py`) against 45 real document-query pairs -- see `domain_gate_eval.py` in this directory for the exact, reusable evaluation logic and how each set below was constructed.

- 21 **positive** pairs: each of the 21 real papers in the corpus + a generic in-domain query. Every paper has real, expert-annotated moulting trait values in the MoultDB ground truth.
- 21 **negative-query** controls: the same 21 real papers, paired with an explicitly non-arthropod moulting query ("Describe feather moulting behaviour in birds.").
- 3 **negative-paper** controls: 3 short, hand-written synthetic passages (bird feather moult, snake ecdysis, human hair shedding -- NOT real literature excerpts) + a generic in-domain query.

## Confusion table

| | Predicted allow=True | Predicted allow=False |
|---|---|---|
| **Expected allow=True** | TP=16 | FN=5 |
| **Expected allow=False** | FP=0 | TN=24 |

**Accuracy: 0.889** (40/45). **Precision: 1.000**. **Recall: 0.762**.

## False negatives — real moulting papers/queries incorrectly rejected

- paper 1 + in-domain query: rejected as `paper_not_relevant`
- paper 19 + in-domain query: rejected as `paper_not_relevant`
- paper 22 + in-domain query: rejected as `paper_not_relevant`
- paper 23 + in-domain query: rejected as `paper_not_relevant`
- paper 45 + in-domain query: rejected as `paper_not_relevant`

All 5 false negatives are the paper-summary gate rejecting a real paper as `paper_not_relevant` because ontology-filtered sentence count fell below the `min_summary_sentences=5` floor -- exactly the same 5 papers (1, 19, 22, 23, 45) independently identified in `sentence_selection_stats.md`. Zero false negatives came from the taxonomy gate or the query gate on these positive pairs -- the bottleneck is specifically the fixed ontology-filtering threshold, not taxonomic scope detection.


## False positives — negative controls incorrectly allowed

None. All 21 negative-query controls and all 3 synthetic negative-paper controls were correctly rejected.


## Example rejections (for the paper's error-analysis discussion)

- paper 1 + non-arthropod query: rejected as `query_out_of_scope` (non-arthropod query terms detected regardless of the paper's own content).
- synthetic_bird_feather + in-domain query: rejected as `paper_out_of_scope` (no arthropod taxonomic signal found in the text).
- paper 1 + in-domain query: rejected as `paper_not_relevant` (real moulting paper, but too few ontology-filtered sentences to pass the summary-sufficiency floor).

## Limitations
- Negative-paper controls are 3 hand-written synthetic passages, not real literature.
- All 21 positive-set papers come from a corpus already curated as moulting-relevant -- this measures recall on "papers a domain expert already judged relevant", not on an unfiltered literature sample.
- n=45 pairs is enough to catch a badly miscalibrated gate and locate exactly which sub-gate causes each failure, not enough to report a statistically tight precision/recall estimate.
