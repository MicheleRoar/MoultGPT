      How it works, and its limits
      
Papers

      
The paper and your question are first checked against an arthropod taxonomy and a moulting ontology. If either is out of scope, nothing is sent to the language model. Otherwise the most relevant sentences go to a remote model, which lists only the traits the text supports.

      
Photographs

      
A YOLO detector finds the living organism and the shed exoskeleton (exuvia). Box geometry and colour features then go to an XGBoost classifier that estimates the moulting stage. If nothing is detected, the image is reported as unresolved.

      
Limits

      
Research prototype. Language-model output can still be wrong, so check it against the source. The image stage is an estimate, and the served classifier is older than the one described in the README (see its status section). The example images on the left are outputs of that served backend.
