How it works

      
Two independent pipelines, one domain: arthropod moulting.

    

    

      

        
1

        
Domain-gated text pipeline

        
A taxonomy lookup and an OWL-ontology concept scorer check that the paper is
        about arthropods and that your question is actually about moulting, before any
        remote LLM call is made.

      

      

        
2

        
Ontology-focused summary

        
Sentences are scored against the moulting ontology and reduced to a compact,
        on-topic summary via TF‑IDF + K‑Means, so the model sees signal, not noise.

      

      

        
3

        
Fine-tuned vision pipeline

        
A YOLO model detects the organism and its exuviae; geometric and colour
        features feed an XGBoost classifier that calls the moulting stage.

      

      

        
4

        
Multi-model, reproducible

        
The text pipeline can run against several remote models side by side
        (eval/compare_models.py), and a local PEFT/LoRA fine-tune is
        available as an open-weight alternative.
